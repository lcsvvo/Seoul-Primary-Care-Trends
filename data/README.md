# Data

| Provider | Download | Local Path |
|---|---|---|
| 건강보험심사평가원 | 의료기관 수 통계에서 지역별 의원 표시과목별 기관수를 분기별 Excel로 다운로드. 2022Q2–2026Q2 17개 파일 | `raw/전국_기관수/` |
| 건강보험심사평가원 | 시도별 종별 요양기관 수, 전국 집계 CSV | `raw/Korea/전국_요양기관수.csv` |
| 행정안전부 | 연령별 인구현황 월간 CSV, 전국. 분기말 집계에 사용 | `raw/전국_인구/` |
| 행정안전부 | 서울 자치구 분기말 주민등록인구 집계. 열은 분기, 시군구, 총인구, 소아비중%, 고령비중% | `raw/Seoul/서울시_인구_전처리.csv` |
| 서울 열린데이터광장 | 서울시 소아의료체계 구축 CSV. 서울시 시설물 정보는 원본 대시보드의 보건기관 레이어 출처 | `raw/Seoul/` |

- [심평원 의료기관 수 통계](https://www.data.go.kr/data/15066015/fileData.do)
- [행정안전부 주민등록 인구통계](https://jumin.mois.go.kr/)
- [서울 열린데이터광장](https://data.seoul.go.kr/)

원본 Excel 이름은 `기관수현황_지역별의원표시과목별_기관수_2022년2분기.xlsx` 형식, 머리글은 셋째 행. 원본 ZIP을 보유한 경우 같은 이름의 폴더를 위 경로에 배치 가능. 서울 인구 파일은 프로젝트에서 만든 집계본이며 원자료 다운로드와 별개로 확보하거나 같은 열로 재구성 필요.

원자료와 중간 패널은 로컬 관리. 공개 워크북에 사용한 집계와 의료기관 위치의 출처는 [Tableau 안내](../dashboard/README.md) 참조.
